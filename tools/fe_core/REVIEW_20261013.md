# fe_core 固定前の監査（2026-10-13）

レビュー担当: Opus（作者＝Fable とは別のサブエージェント。コードを読み、小さな配列で手計算・実行して検算）。
判定: **修正後に固定可** → 下の対応を済ませて **0.2.0 で固定**（Q268 の旧スクリプトとの数値一致は維持）。

## 問題なしと確認された中核

- `pnl_bp`: pos=[1,1,-1,-1,0,1]、close=[100,101,102,100,99,100]、片道 1bp で手計算と一致。ドテンは片道 2 倍、決済は 1 回分。二重のずらしなし。
- `cost_bp_oneway`: 単位換算（往復の価格単位 ÷2 ÷close ×1e4）は正しい。
- `holm`: 独立実装と乱数 2000 ケースで完全一致。
- `nw_t`: 教科書の Newey-West（Bartlett）と一致。`spearman`: scipy と一致。`tstat`・`qlike`・`tsmom_pos`・`sma_pos`・`atr`・`h1_to_d1` の区切り・`z_of` の pct・WS の段数・CATALOG の行番号も確認。
