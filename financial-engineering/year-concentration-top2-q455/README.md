# Q455 日足戦略の封印前の純損益は特定の年に集中しているか（年別寄与の上位 1・2 年を除いた年単位 t）

事前登録: `検証/学問/金融工学/知識/文献/アイデア候補.md` の Q454-C1 の行（接続 Q454・2026-10-22）。設計と実行は Opus（2026-10-22 21:40〜）。計画はスクリプト冒頭に固定。

- スクリプト: `q455_year_concentration.py`（既存の `year_sym.csv` の再集計だけ。pandas/numpy）
- 修正前: `results/q455_year_concentration_before_fix_20261022_2142.py`（NaN の銘柄年を落とし忘れ、Q370 が nan）
- 結果: `results/Q455_result_20261022_214248.json`

## 方法（要点）

- 前提の訂正: アイデア候補が言う「確定・採用済みの日足戦略」は戦略台帳に 1 本も無い。対象を計算前に 10 本へ固定した: S07 の 5 本（Q367〜Q371）＋ 台帳で弱い正として残った未確定 5 本（Q385 BTC/ETH TSMOM60・Q389 キャリー符号・Q408 FOMC 前・Q403 FOMC 日ドル売り・Q414 利上げ局面版）。2 設定あるファイルは param=0。
- 年の損益＝その年の銘柄の pnl_net（コスト後）の等金額平均。封印: year≤2023（2024 上半期は切り捨て）。
- 帰無: 銘柄ごとに年ラベルを循環シフト B=500（銘柄間の同じ年の揃いを壊す）→ 上位 2 年寄与割合の 95 点。
- 判定（Q454-C1 で固定）: 集中なし＝寄与割合 ≤ 帰無 95 点 かつ 上位 2 年を除いた年単位 t≥2。集中あり＝どちらかを外す。総和≤0 は対象外。

点検:
- `data_health`: 再集計なので新たな読み込みは無い。銘柄数は year_sym.csv で数えた（S07 は 48 銘柄、`no_data` は DATA_DIR だけを見るので使わない）。元の実験の gaps（US500/USTECH/WTI 2011）はそのまま含む。
- `null_degenerate`: どれも False。ただし事象型（Q408・Q403・Q414）は全銘柄が同じ発表日に動く構造なので、銘柄別シフトは「同じ年に揃う」ことを壊して帰無の集中を人工的に下げる（p 0.002 は構造の反映で年の集中の証拠ではない）。Q414 は局面外の年（2010〜15・20〜21）が損益 0 で、シフトで 0 の年が散るのも同じ向き。
- S07 の寄与割合 >1 は総和が小さい（平均 0.3〜0.7 bp/日相当）ために不安定。帰無 95 点も 2.6〜53 と広く、割合の枝はここでは情報が無い。
- n_tests=10（戦略ごとの記述。全体判定に Holm は使わない）。

**解釈: 規則の上では 9 本すべて「集中あり」だが、9 本中 8 本は元の年単位 t が 2 未満で「除くと t<2」の枝が自明に満たされただけ。元から t≥2 の唯一の Q414 は上位 2 年（2023・2017）を除くと t 2.32→1.95 で境界、寄与割合の帰無は事象型に不適。問いの対象（確定・採用済みの日足戦略）が存在しないので、問いには答えられない。** 記述として残すこと: S07 の正の総和は 2008 と 2017（L120 は 2013）でほぼ全部が出ている（上位 1 年の寄与 0.6〜0.99）。今後、確定・採用候補が出たら、この再集計（上位 2 年除外後の年 t）を関門の副次表示にする価値はある。
