## 方法（要点）

- 定義: 持ち高 = sign(13 週リターン)×(建玉が 13 週前より多ければ +1・少なければ −1)
- 枠: Q593 と同じ対応表（17 銘柄）と約定の決まり: 報告日（火曜）+6 日以降の最初の営業日の終値で持ち替え（公表は金曜）。銘柄ごとに年率 10% にそろえて銘柄数で割る・片道コストは段階 1 の仮置き（FX 1bp・指数 2〜3bp・金属 2〜8bp・エネルギー 5〜10bp）・スワップなし・評価 2012-01〜2024-06・前後半の境 2017-01-01
- 帰無: 合図の週を循環シフト（26 週以上・B=500）。統計量はコスト後の日次平均
