## 読み
- **指標の反応は普通の日の同じ動きと差がない**（z 0.12）。発表の 2 時間で動いた方向に、その後の数日のドリフトは見えない。Q219 の「NFP の 1〜4 時間は続かない」が 5 営業日でも同じ。
- **反転の向きも稼げない**（コスト前 +2.66・コスト後 −2.05 bp/件）。続きも戻りもない。
- 種類別もどれも弱い。CPI 58 件 −2.7、NFP 53 件 −12.4、FOMC 32 件 −10.3（前半 +25.3・後半 −50.6）。
- 保有を短くしても同じ。24 本 +1.3 bp（t 0.34）、72 本 −2.4 bp（t −0.39）。閾値なしは 423 件 −6.5 bp（t −1.39）。
- 1 件のコストはスプレッド 2.0 bp とスワップ 3.4 bp。負けの主因はコストではなく、コスト前が 0 近いこと。
