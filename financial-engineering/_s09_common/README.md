# _s09_common — S09（キャリー＝政策金利差）の検証スクリプト共通部（検証フォルダではない）

`s09carry.py` は Q389〜Q392（2026-10-22 夜の /lab-plan ターミナル版 N=4）が共用する薄い層。`fe_core` の `Runner` を継承した `CarryRunner` に
「金利差の付与（df["carry_diff"]）→ スワップ損益（cells と規程モードの両方）→ 封印（2024-07-01）→ 符号反転帰無 → S09 の 3 分岐」を足したもの。
`gen_fe_index.py` は `_` で始まるフォルダを飛ばすので INDEX には載らない。

- `fe_core` は書き換えない。土台に移したい候補: `rate_diff`・`swap_bp`・`total_return_close`・`null_signflip`（2 本目以降のデータ源を足すときに `fe_core/carry.py` として CATALOG に載せる）。
- **データ源（入力基準 2026-10-22 改定後の最初の 1 つ）**: `検証/_データ/raw/rates/policy_<CCY>.csv`（BIS WS_CBPOL・実施日ベース・8 通貨）。時刻 t の合図に使うのは **t−1 暦日に実施中の値**（発表→実施のずれ対策・rates/README）。3 か月金利・フォワードポイントは未取得なので使わない。
- **スワップの近似**: 建玉 held[t]=pos[t−1] が t−1→t の暦日数（週末またぎ 3 日）ぶん金利差を受け取り（売りは払い）、マークアップ年 0.75%（台帳の 0.5〜1% の中点・固定）を向きによらず常に払う。gross には金利差だけ、net には金利差 − マークアップ − スプレッド。本番は業者の実測スワップに置き換える（`トレード/執行/`）。
- **帰無**: キャリー符号・横断順位は年単位で動かないので、循環シフトでは帰無が観測と一致しうる（符号が一度も変わらないペアは不変）。Q389・Q392 は `null_signflip`（銘柄ごとに独立な ±1）。Q390・Q391（TSMOM を含む）は循環シフト。
- **判定（`judge_s09`・事前固定）**: 支持＝規程モード（スワップ込み・封印前・境 2017）の前後半とも年単位 t≥2 かつ max_dd≥−6%、かつ等金額の全期間 z≥2。棄却＝等金額の全期間 z<1、または規程モードの t_all<0。ほか → 未確定。`rule_mode` にはスワップ込みと `*_no_swap` を並べ、`rule_mode.swap.delta_t_pre_swap／delta_t_post_swap` で「データ源を足して関門の数字が上がったか」を読む（台帳の採否規則）。
- **族内の本数**: S09 は 4 本×2 設定＝8。Holm は各スクリプトの pre/post（m=2）だけなので、事後の判断で 8 本を数えること。
- 使い方: 各スクリプトの冒頭で `sys.path.insert(0, os.path.join(HERE, "..", "_s09_common"))` → `import s09carry as S9` → `S9.main(SPEC, strategy, HERE, null=...)`。横断版（Q392）は `CarryRunner.loaded` からパネルを組むので `CarryRunner` を直接作る。
