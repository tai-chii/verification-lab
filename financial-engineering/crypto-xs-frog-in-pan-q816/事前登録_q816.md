# 事前登録 Q816（2026-11-24・Fable・変更禁止）

- **問い**: 暗号資産の永久先物で、値動きが小刻みな銘柄（28 日の上げ下げ日数で作る離散度が母集団の中央値以下）に限ったモメンタムは、コスト・資金調達後に残るか
- **出典**: Da, Gurun, Warachka (2014) frog-in-the-pan／Q739（S68 モメンタム）の条件付け
- **データ**: 作業層/大容量/crypto_xs/{klines,funding,metrics}/<SYM>.csv（Binance の USDT 建て永久先物・日足。date < 2024-07-01 だけ読む。klines_seal・funding_seal は読まない）
- **定義**: 離散度 ID = sign(28 日リターン)×(下げ日の割合−上げ日の割合)。ID が中央値以下の銘柄だけ残し、合図 = 28 日リターン。高い側を買う
- **測り方**: S68（Q739）と同じ枠: 毎週月曜に組み替え・判断は日曜までの日足・母集団は 30 日の売買代金の上位 30（株や金など暗号資産以外の先物は除く）・合図の高い側 6 本を買い低い側 6 本を売り（各 0.5÷6）・片道 0.10% × 入れ替えた名目・資金調達の受け払い込み・評価 2020-01-06〜2024-06・前後半の境 2022-04-01
- **帰無**: 毎週、母集団の中で合図を並べ替える（B=500）。統計量はコスト・資金調達後の日次平均
- **判定（事前固定）**: 支持（フォワード候補）: コスト後の日次平均 > 0 かつ NW t ≥ 2.0 かつ 前後半とも平均 > 0 かつ 帰無 z ≥ 2.0。棄却: 全期間の日次平均 ≤ 0 または 帰無 z < 1.0。それ以外: 未確定。
- **多重比較**: 暗号資産の横断 10 本（Q807〜Q816）。支持が出たら Holm で補正して解釈する
- **封印**: 2024-07-01 以降は読まない
