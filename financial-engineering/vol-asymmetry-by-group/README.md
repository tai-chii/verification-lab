## 結果

実行: 2026-10-11 15:33（Mac・B=500）。結果 JSON: `results/Q247_result_20261011_153333.json`。欠損銘柄なし（15 銘柄すべて走った。BTCUSD は pre が足りず post のみ）。

- 指数（US500・USTECH）: 前半も後半も γ>0・z≥2 を楽々クリア（US500 pre γ=0.355 z=5.69／post γ=0.409 z=10.33、USTECH pre γ=0.354 z=6.20／post γ=0.345 z=9.63）。Black 1976 の負のリターン後のボラ上昇はこの土俵でも強く再現。
- 金（XAUUSD）: 前後半とも γ はわずかに正（pre γ=0.068 z=1.88、post γ=0.036 z=1.14）。z は 2 を超えず、Baur 2012 の「逆の非対称（γ<0）」は再現しない。かといって「指数と同じ向き（γ>0 かつ z≥2）」でもないので棄却も立たない。
- FX8: 前半で |z|<2 だったのは EURUSD・GBPUSD の 2 本、後半は GBPUSD・AUDUSD・USDCAD の 3 本。残りの USDJPY・USDCHF・EURJPY・GBPJPY は前後半とも z≥2 の有意な**正の**非対称（USDJPY 全期間 z=4.82、USDCHF 4.37、EURJPY 4.63、GBPJPY 4.61）で、FX8 の 6 本以上 null という事前条件は満たさない。USDCAD は前半 γ=−0.12 z=−3.99 で**負の**非対称、EURUSD は前半 null → 後半 γ=−0.13 z=−3.93 で符号が切り替わる。
- その他（記述）: WTI・UKOIL は前後半とも γ>0・z 大（UKOIL 全期間 z=7.16）、XAGUSD は前半のみ z=2.18、BTCUSD（post のみ）は z=2.05。

判定: **未確定**（事前固定の支持条件も「金の逆の非対称を棄却」の条件も、どちらも満たさない）。
解釈: **棄却**（Fable 2026-10-10 の「株価指数は負・金は正・FX は無し」という3群への分かれ方は支持されない。実際には (i) 指数は強い正の非対称を示す（既知の再現）、(ii) 金は非対称そのものが有意に出ない（Baur 2012 の逆の非対称も再現せず）、(iii) FX は JPY クロスと USDCHF で有意な正、USDCAD で有意な負、EURUSD は期間で符号反転と、群として一色では塗れない。原油2本は指数と同向きで強い）。多重比較 11 銘柄×2 期間 = 22 本に対し、指数4本と JPY クロス3本・USDCHF 2本の z は Holm α=0.05 を楽に通る。
