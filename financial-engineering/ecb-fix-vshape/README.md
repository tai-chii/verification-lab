## 方法（要点）

- 仮説: H: ECB 参照レート時刻の前 1 時間（CET 13 時台）のドル（6 組等加重）は上がり、後 1 時間（14 時台）は下がる: D = pre − post > 0。
- 定義: CET は Europe/Berlin（夏時間込み）。ドルのリターンは Q229 と同じ符号規則。2016-07-01 以降を主（14:15）、以前は 14:30 で同じ時間帯（副次）。対照: 同じ日の 10 時台 − 11 時台。
- 測るもの: D [bp] の年単位 t（全期間・前半 2008–2016／後半 2017–）、pre と post それぞれの平均。
- 帰無: 日ごとの pre/post ラベルを入れ替える（符号並べ替え）B=2000 → D の帰無分布 → z。
- 多重比較: 判定は D の前後半 2 本。対照・時刻変更前は記述。
- 捨てた案: 約3: 15 分足（EURUSD・USDJPY しか無い）、月末だけ（Q229 と混ざる）、EUR 単独。
- 先行研究チェック: WebSearch 2026-10-10「ECB reference rate 14:15 CET fixing exchange rate behaviour around fixing intraday pattern empirical」: Krohn・Mueller・Whelan「Foreign Exchange Fixings and Returns around the Clock」（WU 2022）、BIS 2022 Mueller スライド、ECB プレスリリース 2015-12-07。 ECB fix 周りは論文で触れられるが、手元 H1・FX6・2008–2026 前後半・符号並べ替え帰無で判定する形は未確認（移植）。

## 判定（事前固定）

前後半とも D>0 かつ z≥2 → 支持。全期間 z<1 → 棄却。それ以外 → 未確定。

- 副次（記述扱い）: 時刻変更後 2016-07 以降（14:15・11 年・2594 日）D=0.74 bp・t=3.77、時刻変更前 2016-07 まで（14:30・9 年・2211 日）D=−0.005 bp・t=−0.02。V 字は 14:15 期にだけ出て、14:30 期は実質ゼロ。対照（10 時台 − 11 時台）は全期間 D_ctl=−0.20、後半 +0.23（弱い反対向き）。
- **解釈**: 14:30 → 14:15 の時刻変更以降にのみ borderline の V 字が出る形で、知見 Q056（Tokyo・London fix の V 字は 2020 年以降弱まる）と整合する「2016 年の時刻変更前と後」という別の切れ目でも効果の有無が替わる現象。大きさ 0.8 bp は FX の往復コスト（主要通貨で 1〜2 bp 相当）を下回り、売買には使えない。
