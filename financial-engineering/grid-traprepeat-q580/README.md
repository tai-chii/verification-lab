## 方法（要点）

- 年ごとに独立: 起点＝年初の H1 終値。間隔 Δ = 0.5 × ATR20(D1・前年末) / 前年末の終値。起点の下に買い 20 本・上に売り 20 本、利確 1 間隔、リピート。年末に全決済（含み損を確定）。コストは約定ごとに片道（段階 1）。スワップなし。
- 経路は H1 の終値だけ。終値で水準をまたいだら水準の価格で約定。**試走で、この扱いは連続の経路より負に偏る（合成ランダムウォークで −68±12 bp/年）と確認**。帰無も同じ扱いなので z は偏らないが、「純損益 > 0」の t は保守的。記述に帰無平均との差（excess）の t を出す。
- 帰無: 銘柄×年ごとに H1 の対数リターンを年内で並べ替え（起点と年末の価格は同じ・自己相関だけ壊す）× B=300 → FX8 全期間の平均純損益の z。
- 記述（判定外）: excess の t、総損益（コスト前）、往復回数、年末の含み損、最大下落（含み損込み）、最悪の年、k=0.25・1.0、TREND7、銘柄別 z。
- 先行研究チェック（WebSearch 2026-10-30・英語）: "grid trading strategy foreign exchange backtest profitability random walk mean reversion academic paper"。格子の吸収壁つき確率過程の理論（Virtus Interpress）、BTC のグリッド＝マーケットメイク（Stevens）、個人ブログ・TradingView・MQL5。主要 FX で含み損込み・コスト後を年内並べ替えのランダムウォークと前後半で比べた実証は見つからない（条件の穴）。
- 捨てた案の数: 約 5（範囲を過去の高安から決める／足の中の高値安値で約定／年をまたぐ持ち越し／スワップを外部金利から／k・N の格子探索）。

### 解釈

- **儲からず、ランダムウォークより良くもない**: 前後半とも t<1（負）、z<2 で棄却。実データは並べ替えた系列より格子に不利（z −2.6）。Q579 の「H1 の分散比 < 1」は格子の損益には届かなかった。
- **損益の形はオプションの売り**: 年の中央値 +23 bp・上位 1/4 は +98 bp 以上だが、最悪の年 −833 bp・下位 1/4 は −155 bp 以下。年末に確定する含み損（平均 −180 bp）が実現益を食う。
- **間隔を広げるとマシだが正にならない**（記述）: k=0.25 −127 bp、k=1.0 −17 bp（後半 +0.2・t 0.02）。TREND7 は −456 bp。
- **z<0 の読み方の注意**: 年内並べ替えは自己相関とボラ・クラスタリングを同時に壊す。実データが不利な理由がどちらかは分けていない。
- 限界: 終値だけの約定判定（負に偏る・帰無も同じ）、スワップなし、年ごとに起点を置き直す設計（実際のトラリピは範囲を何年も固定する）。
