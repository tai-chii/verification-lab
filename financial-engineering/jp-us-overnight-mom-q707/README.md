- 記述（`res["sub"][mkt]["intraday_signal"]`・合否に使わない）: 同じ窓の日中リターン log(C_d) − log(O_d) の和をシグナルにした結果（同じ測り方・帰無は取らない）。符号が逆になるかの確かめ。`daily_intraday_{jp,us}_q707.csv` も出る。
