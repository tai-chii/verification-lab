## 方法（要点）

- 仮説: pos[t]=sign(close[t]−close[t−60])（t の終値で決め t+1 から保有）。D = 円の組 3 本の等加重の日次純損益 − ドルの組 5 本の等加重の日次純損益 [bp]、年ごとの平均を年で平均したもの。D は前後半とも >0 で、8 銘柄から 3 本を『円の組』と呼ぶ全 56 通りの中で上位 5% に入る
- 測るもの: D（円の組 − ドルの組、年単位の日平均 bp、段階1コスト後）と年単位 t、各組の純損益・粗利・Sharpe。記述: L=20/120 の D
- 帰無: 8 銘柄から 3 本を円の組とする全 56 通りで D を計算し、実際の D の正確な順位 p（乱数なし）
- 多重比較: 判定は 2 本（前後半の両方を要求する交差のため Holm なし）。ほかの設定・群は記述
- 先行研究チェック: WebSearch 2026-10-16・standard・検索語 "time series momentum yen crosses versus dollar pairs daily FX trend following performance comparison"。見つかったもの: CXO Advisory の通貨モメンタム検定、Deutsche Bank 2007 の FX モメンタム資料、QuantInsti の主要通貨のトレンドフォロー（ブログ）。未確認: 円クロスとドルストレートの順張りの差を、組ラベルの正確な並べ替え帰無で前後半に分けて測った研究は見当たらない（条件の穴）
- 捨てた案の数: 約3: H4 で再確認（既知見の繰り返し）、L の掃引 20/120（判定は 1 本に固定）、通貨強度でのグループ分け（Q291 系と重なる）
