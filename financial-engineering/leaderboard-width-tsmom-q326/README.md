## 方法（要点）

- 15銘柄 D1_fromH1・TSMOM L∈{5..300}（60本）・片道コスト段階1（Q139 の pnl_matrix を写した）
- セル＝(銘柄, 選択年 t)、t と t+1 で 60 本すべて定義されるものだけ（前半 97・後半 133 セル、各 8・9 年）
- 順位 j は年 t の純損益の降順。L(j)＝翌年の順位 j の純損益の平均。幅 W のランダム部分集合で選ばれる順位の確率は C(60−j,W−1)/C(60,W)（重みの和＝1 を確認）
- 判定量 Δ＝D(60)−D(1)＝翌年の順位1 − 翌年の60本平均（年単位 t）、Spearman(j, L(j))
- 帰無: 翌年の日次リターンを暦年内で並べ替え（Q139 と同じ）、B=300・seed 20261019

- 読み方: Q171 の PBO 0.88 は「上位が中位より悪い」ことを言っていたが、Wang の Corollary 1 の条件（幅が害しうる）はそれだけでは足りず、全幅で選ぶ1位そのものが平均より有意に悪いかが要る。手元の 60 本ではそれは測れない大きさ（|t|<1）。「格子は何本までなら選ぶ価値があるか」の答えは「何本でも、でたらめに1本選ぶのと区別できない」。
