## 方法（要点）

- 仮説: 15 銘柄のうち、ρ_high − ρ_low > 0 かつ Holm 補正後に有意（m=15、α=0.05）な銘柄が ≥ 4 本（1/4 弱）→ 支持。高ボラ局面で衝撃持続性が高い。
- 測るもの: 各銘柄の Δρ=ρ_high−ρ_low（全期間・前後半）、Holm 補正後 p、15 銘柄中の有意本数 K。
- 帰無: 銘柄内で月のラベル（high/low）を並べ替え（B=1000）→ 各並べ替えで Δρ を再計算 → 観測との z・片側 p_right。
- 多重比較: 判定は全期間 Δρ の p_right を 15 銘柄分 Holm（m=15）。前後半は記述。
- 先行研究チェック: WebSearch 2026-10-14・英語・"daily return autocorrelation volatility regime GARCH shock persistence 15 assets cross-section"。Cont (2001) "Volatility Clustering"（絶対値・二乗の自己相関は長期）、Zivot GARCH 実務ノート。15 銘柄 D1 で符号つき 1 次自己相関を循環シフト帰無と Holm 補正で判定する実証は未確認（移植）。
- 捨てた案の数: 約4: (i) 絶対値や二乗の自己相関（Cont 2001 と重複）、(ii) GARCH モデル推定（計算重い）、(iii) 3 分位、(iv) 時間足 H1（Q252 の M15 と重複）。
- 知識の締め切り: Claude の知識はおよそ 2026-06。本データの終端も 2026-06。
- 委託の確かめ方: 設計・コード・実行・解釈は Opus 本体の自動運転。委託なし。

## 判定（事前固定）

支持: K ≥ 4。棄却: K ≤ 1。未確定: K ∈ {2, 3}。補助情報: 前後半それぞれの Δρ の符号（判定は変えない）。

## 結果

- 実行: 2026-10-14（B=1000、約 2 分 20 秒、Opus 4.7 本体の自動運転）。結果 `results/Q294_result_20261014_020003.json`・`results/Q294_symbols_20261014_020003.csv`。
- **K=0**（15 銘柄とも Holm 補正後 p=1.0）。全期間 Δρ の符号は +3／−12（正: EURUSD +0.038, GBPUSD +0.057, USDCAD +0.012。負: USTECH −0.171, US500 −0.114 ほか）。|z| 最大 1.91 で帰無は退化していない。
- 前後半: EURUSD／GBPUSD は pre のみ正（+0.09, +0.10）、post ではほぼ 0。USTECH は pre/post とも −0.13〜−0.16 で一貫。符号も大きさも銘柄・期間でばらつき、仮説の方向への集中は見られない。
- `data_health`: 15 銘柄とも `ok`、`failed` なし。gaps は WTI／UKOIL／US500／USTECH の 2011〜2014 の月に集中するが、月単位のレジーム割り当てなので gap のない月で ret ペアを集めるだけ、判定に影響しない。
- `n_tests`=15 と Holm m=15 は一致、`null_degenerate` フラグなし、循環シフトではなく月ラベル並べ替え（事前登録どおり）。

判定: **棄却**（事前固定の規則「K ≤ 1 → 棄却」に該当。15 銘柄 D1 では符号つき 1 次自己相関のボラ局面差は Loubaris2026-3 の持続性差と整合しない。Cont 2001 の指摘どおり、絶対値／二乗の自己相関と違い**符号つき**自己相関には高/低ボラ月の体系的差がない）。
