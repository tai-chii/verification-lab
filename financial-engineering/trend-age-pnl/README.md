## 方法（要点）

- 仮説: H: TSMOM60 の合図が最後に反転してからの経過日数 a を 3 区分（a≤10・11〜40・41 以上）に分けると、翌日の順張り粗利 [bp] は若い区分ほど高く、D=若−老>0。
- 定義: a: 合図の符号が直近で変わった日からの営業日数。粗利 = pos[t−1]·ret[t]·1e4（コストは区分で変わらないので粗利で測る。純損益は記述）。
- 測るもの: 年×銘柄の D=若(a≤10)−老(a≥41) [bp/日]（年単位 t・all15/fx8/trend7）、3 区分の平均。前後半。
- 帰無: a の区分ラベルを年内で並べ替え（perm_within）B=500 → D の帰無分布 → z。
- 多重比較: 判定は all15 の D の前後半 2 本。群別・3 区分の平均は記述。
- 捨てた案: 約3: a を連続量で回帰する（非線形の可能性）、反転の「大きさ」で分ける、H1 への移植。
- 先行研究チェック: WebSearch 2026-10-10「trend age days since signal flip trend following returns decay fresh signals stronger」: Quantpedia「Trend Breaks in Trend-Following Strategies」、arXiv 2607.01550「Introduction to the Trend-Following Puzzle」、CFM のノート。 合図の年齢の 3 区分を 15 銘柄・前後半・年内並べ替え帰無で測る形は未確認（追試＋条件の穴）。

## 判定（事前固定）

all15 前後半とも D>0 かつ t≥2 かつ z≥2 → 支持（若い合図ほど強い）。前後半とも t≤−2 かつ z≤−2 → 逆向きで確定（古い合図ほど強い）。それ以外 → 未確定。

**判定: 未確定**（人の解釈）。方向は仮説どおり（若い a≤10 の合図ほど翌日の順張り粗利が高い。全期間 D=+6.90 bp/日・t=+2.70・z=+4.05）だが、事前固定した判定は all15 の **前後半 2 本の D** に対して「どちらも D>0 かつ t≥2 かつ z≥2」を要求する。前半（2008-2016、9 年）は **D=+2.76 bp/日・t=+0.65・z=+1.29（pct=0.898）** で基準に届かず、後半（2017-2026、10 年）は **D=+10.62 bp/日・t=+3.93・z=+4.16（pct=1.0）** で強い。方向は一致するが強さが期間に依存するため、固定規則どおり未確定。

- all15 全期間: 若 5.12 bp／中 3.58 bp／老 −2.49 bp（粗利・年単位・銘柄平均→年平均。純損益: 若 4.17 bp／中 3.58 bp／老 −2.49 bp）
- 群別（判定外・記述）: trend7 の後半で D=+18.79 bp/日・t=+3.40・z は未集計、fx8 の後半で D=+3.05 bp/日・t=+2.39。方向は常に正、強さは株価指数・原油・金を含むトレンド 7 でもっとも大きい。
- 年齢区分の分布: 若 30.6%／中 33.8%／老 35.6%（15 資産全期間）。概ね均衡で、特定の区分が極端に少ない年は無し。

## 解釈（Opus・2026-10-13）

- 若い合図ほど翌日の順張り粗利が高いという方向は、**15 資産でも**（元の Quantpedia 要旨は株・先物の文脈）2008-2026 では成立する。ただし「どの期間でも成立するか」は満たさない。
- 2017 年以降で効果が強いのは、Q143（減衰）・Q251（時間ストップ）と整合的（時間が経った合図のパフォーマンスが相対的に落ちる方向）。順張り戦略の混雑度の変化やトレンドの平均持続時間の短縮が候補の説明だが、本検証では確かめていない。
- 前半（2008-2016）で弱い理由として、金融危機後のトレンド継続性が強く「古い合図」も健全に稼いだ可能性が考えられる（old_bp pre=−1.71 vs post=−3.07、old の悪化幅のほうが若の改善幅より大きい）。
- 時系列の正の自己相関（短期継続性）そのものの検証ではなく、「合図からの経過日数」という年齢指標の有用性の検証である点に注意。年齢そのものが減衰を測るので、Q143（減衰：合図の情報は時間とともに弱まる）の 1 つの操作化。
- Opus 見直しの判定: 期間依存が強いが方向は一致し、関門（先行研究チェック）も通っており、escalate の必要なし。固定規則どおり未確定で完了。
