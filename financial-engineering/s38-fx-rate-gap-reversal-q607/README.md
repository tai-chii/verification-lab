# Q607 S38 FX の 2 年金利差で説明できない 20 日の値動きは平均回帰するか

事前登録: `事前登録_q607.md`（変更禁止）。スクリプト: `kensho_s38_fx_rate_gap_q607.py`（直接型）。実行: `作業層/大容量/venv_forward/bin/python kensho_s38_fx_rate_gap_q607.py`（2 分弱）。

## 実装の解釈（事前登録に書いていない点。結果を見る前に決めた）

- 手じまいの足から次の合図を探す（Q605 と同じ）。同じ向きの再入場を止めた版は記述に出した。
- Dukascopy の ask が手元にあるのは 19 本中 9 本だけ。残り 10 本は XM 実測比×価格のみ。
- Q591 の実測に無いクロス 5 本（EURAUD・EURCAD・GBPAUD・GBPCAD・GBPCHF）: スワップは MT5 の仕様 CSV から同じ換算、スプレッドは実測 14 本の中央値 2.12bp（事前登録どおり）。クロスの実スプレッドより狭い可能性があり、甘い側。
- 政策金利は `C.rate` の 1 日遅れ。スワップは晩ごとにその日の金利差で積む。
- 共通部は `../_fx_rates_common/fxrates.py`。

## 判定（事前固定）

A PF ≥ 1.05、B 日次 NW t ≥ 1.5、C 前後半とも平均 > 0、D 帰無 z ≥ 1.5、E β=0 版との日次差の平均 > 0 かつ NW t ≥ 1、F composite。A〜F すべて→支持。A〜D のどれか不成立→棄却。A〜D は満たすが E か F 不成立→未確定。

## 結果

判定: **棄却**（2026-11-01 Opus 実行。`results/result_q607.json`。B が不成立）

| 項目 | 値 | 関門 |
|---|---|---|
| 件数・平均保有 | 413 件（月 2.5 件）・13.2 本 | 記述 |
| コスト前 → コスト後 | +27.7bp → +16.2bp（スワップ −9.3・スプレッド −2.2） | 記述 |
| A PF | 1.19 | 通過 |
| B 日次 NW t | 0.67 | **不通過** |
| C 前後半 | +15.4bp・+16.9bp | 通過 |
| D 帰無 z | 2.88 | 通過 |
| E β=0 との差 | −0.014bp/日・t −0.19 | **不通過** |
| F composite | 単体 Sharpe 0.28 | **不通過**（相関は全部 0.15 以下） |

**解釈**: 金利の情報は反転に何も足さない。同じ規則の素の反転（494 件・+15.2bp・PF 1.18・NW t 0.75）と同じ成績で、水準回帰の版は PF 0.99。
1 件の t は 1.29、月で束ねると 0.95。生涯損益 354bp のうち 147bp は 2015-01-15（SNB）の 1 日で、CHF の 2 件を除くと +12.2bp・PF 1.15。月 2.5 件ではスペックの月 8〜20 回にも届かない。
帰無 z 2.88 はコスト前のタイミングの偏りを示すが、基準の −12.9bp はコストの分だけ低く、コスト後の優位の証拠にはならない。閾値を変えて作り直さない。
