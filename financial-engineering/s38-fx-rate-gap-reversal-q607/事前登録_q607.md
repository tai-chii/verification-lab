## 【仮説】
為替は金利差の変化に反応するが、それを超えて動いた分はフローやポジションの一時的な偏りで、数週間で戻る。素の反転（S05）が失敗したのは、金利に裏付けられた持続的な動きまで逆張りしていたからで、それを除けば反転が残る。

## 【定義（合図→ポジション。shift の扱い）】
金利差 `d_t = y_base − y_quote`（%）。金利の欠けは前方埋め最大 5 営業日で、それを超える日は `d` も `z` も NaN とする。

日付 t で、同じ日付どうしの価格と金利を突き合わせて次を計算する。

1. `r_t = Δlog(close)`、`x_t = Δd_t`。
2. `β_t`: 直近 252 本で `r` を `x` に切片なしで回帰する。有効本数 200 未満は NaN。**β_t ≤ 0 なら新規に建てない。**
3. `e_i = r_i − β_t·x_i`、`σ_t = e の直近 252 本の標準偏差`。
4. 乖離 `z_t = Σ(直近 20 本の e_i) / (σ_t·√20)`。

売買:
- 建てる: `z_t ≥ 2` で売り、`z_t ≤ −2` で買い。1 ペア 1 本、名目は全ペア同じ。
- 手じまい: 毎日の `z` を、その日の β・σ で計算し直す。`|z| ≤ 0.5`、`|z| ≥ 4`、保有 20 本のどれか。
- 約定（**shift**）: 日付 t の金利は当日の終値時点で揃わない。t の合図は **t+1 の終値の後に確定したものとして扱い、t+2 の始値で約定**する。

調整値は 252・20・2・0.5・4・20 本に固定し、掃引しない。

## 【判定（事前固定・変更禁止）】
本判定の対象は上の定義の 1 本だけ。学習はしないので、全期間（封印前）を「学習外」として扱う。

- A. コスト後 PF ≥ 1.05
- B. 日次 NW t ≥ 1.5
- C. 前後半（2017-01-01）とも平均 > 0
- D. 帰無 z ≥ 1.5
- E. 金利の付加価値: 同じ規則で β=0 とした素の反転（`z0 = Σ直近20本の r / (σ_r·√20)`、コストも同じ）に対し、日次損益の差の平均 > 0 かつ NW t ≥ 1
- F. composite: `tools/composite_gate.py` の相関 ≤ 0.15・単体 Sharpe ≥ 0.5・合成 Sharpe が全期間と 2021〜 で下がらない

分岐:
- **支持（フォワード候補）**: A〜F をすべて満たす。封印期間の判定は別 ID で 1 回だけ行う。
- **棄却**: A・B・C・D のどれかを満たさない。
- **未確定**: A〜D は満たすが E か F を満たさない。素の反転の言い換えか、既存 bot の重複である可能性があるので、昇格させない。
