## 方法（要点）

- **Q320 の合成を作り直した理由（測る前に SPEC に記載）**: Q320 の J4 は、ポジションを銘柄ごとに独立に作り、損益 x だけが銘柄間で相関する世界だった。この世界では、並べ替え統計の銘柄間の交差項が E[s_perm·s]=0 で消える。だから日付を共通に並べ替えても交差項は戻らない。現実の帰無ではポジションも収益も銘柄間で相関し、損益の相関はその積から生まれる
- 帰無 M（判定に使う）: 収益は銘柄ごとに平均を引いた実収益の「日付ごとの 15 銘柄の行」を定常ブートストラップ（平均ブロック 20 日）。ポジションは実際の L=60 の保有行列を全銘柄共通に循環シフト（k〜[252, T−252]）。収益とポジションは独立で腕なし。横の相関は両方に実データのまま残る
- 世界 V（記述・Q320 型）: ポジションを銘柄ごとに別の k でシフト（横の相関なし）。損益は抽出した行そのもの
- 判定 J4a: 銘柄 × 年の中で並べ替え（fe_core.perm_within と同じ）。J4b: 年の中で日付を 1 つの並べ替えで動かし、全銘柄のポジションの行を一緒に動かす。統計は年単位平均、B=199、両側 perm_p<0.05
- 事前登録からの変更点: なし

## 判定（事前固定）

M の J4b ≤ 6.0% なら回復（支持）、≥ 7.5% なら未回復（棄却）、ほか未確定。付記: M の J4a ≤ 6.0% なら、Q320 の 16% は合成の作り由来と読む。

## 結果

判定: **支持（回復）**（M の J4b = 5.0% ≤ 6.0%）

**解釈: 銘柄ごとの年内並べ替えは、現実型の帰無でも膨らむ（12.4%）。Q320 の 16% は合成の作りだけのせいではない。全銘柄共通の日付の並べ替えにすると名目どおり（5.0%）。帰無の sd は共通版が 1.28 倍。** Q320 型の世界（ポジション無相関）では共通版も 12.7% のままで、事前の見込みどおり。Q320 の診断「主因は銘柄間の相関」は、共通版で直るという形で裏づけられた。

| 判定 | M 現実型（判定） | V Q320 型（記述） |
|---|---|---|
| J4a 銘柄 × 年の並べ替え p<0.05 | **12.4%**（\|z\|≥1.96 で 13.6%） | 14.3% |
| J4b 日付共通の並べ替え p<0.05 | **5.0%**（\|z\|≥1.96 で 5.8%） | 12.7% |
| 帰無 sd の比 J4b/J4a（平均） | 1.28 | 1.04 |
| J1 年単位 \|t\|≥2（参考） | 6.3% | 7.0% |
| J2 日クラスタ \|t\|≥1.96（参考） | 5.35% | 4.45% |

（2,000 回。二項の 95% 上限は 6.0%）

- 実データ（記述・コストなし・B=999）: L=60 の年単位平均 1.20bp/日。J4a は z=−2.49・p=0.014、J4b は z=−1.88・p=0.063。帰無 sd は 0.53 → 0.69。銘柄間の平均相関はポジション 0.067、収益 0.113、損益 0.137。並べ替えの帰無の平均（2.5bp）が観測より高いのは、年の中のポジションと収益の平均どうしの積が帰無に残るため（年内並べ替えの性質。この問いの外）
