# Q451 BB幅収縮度のボラ予測への増分（wide48 D1）

- 問い: 48 銘柄 D1 で、BB 幅の収縮度（過去 252 本の中のパーセンタイル）は、σ20・σ60 と直近 20 日の向きを統制した後も、翌 20 日の実現ボラに増分を持つか（Q450-C1、出典は Quanter Lab のスクイーズ記事 2 本）。
- 設計・実行: Opus（2026-10-22、ループ）。計画はスクリプト冒頭に固定（土台を直接使う型）。
- スクリプト: `kensho_bb_squeeze_vol_q451.py`（`--smoke` で経路確認）
- データ: wide48 の D1_fromH1、封印 time<2024-07-01。48/48 銘柄を読めた（`results/Q451_year_sym_*.csv`）。failed 0、欠けのある銘柄 14（指数・原油・債券）。
- 式: log(翌20日実現ボラ) = a + b1·log σ20 + b2·log σ60 + b3·dir20 + b4·収縮度（束ねた OLS）。標本外は年ごとの拡大窓（試験 2013〜2024）。帰無は収縮度列の銘柄内循環シフト B=500。
- 判定規則（事前固定）: 支持＝|t(b4)|≥2・前後半同符号・ΔR² が帰無 95 点超。棄却＝|t(b4)|<1。ほか未確定。

## 結果（`results/Q451_result_20261022_213114.json`）

| 項目 | 値 |
|---|---|
| 行数 | 149,768（48 銘柄・2009〜2024-06） |
| b4 の年単位 t（16 年） | **−1.19**（帰無 2.5〜97.5 点 −2.04〜2.63、両側 p=0.27） |
| b4 前半（<2017）/ 後半 | +0.005 / −0.066（符号が割れる） |
| 標本外 R²（基準 σ20・σ60） | 0.746 |
| ΔR²（式 − 基準） | +0.00002（帰無 95 点 0.00025、片側 p=0.99） |
| 参考: ΔR²（式 − 基準＋dir20） | −0.00019（収縮度を足すと標本外で悪化） |
| 参考: 欠け 14 銘柄を除く（34 銘柄） | t=−0.72、ΔR²(対 dir20 込み) −0.00029 |
| corr(収縮度, log σ20) | 0.26 |

帰無は退化していない（ΔR² の帰無が正に寄るのは dir20 の寄与が式側にだけ入るため。実データの ΔR² はその帰無の 2.5 点も下回る）。

判定: **未確定**（|t|=1.19 で棄却線 1 と支持線 2 の間）

**解釈: 実質的に増分なし。** 標本外では σ20・σ60（R²≈0.75）に対して収縮度は何も足さず、dir20 込みの基準に足すとむしろ悪化する。年ごとの b4 は前後半で符号が割れ、t が 1 を超えたのは後半の負の年（2015・2019・2020 など）に引っ張られたため。Quanter Lab の「スクイーズ固有の上乗せは 1〜2pt 以下」と矛盾しない。事前予想（b4 は 0 と区別できない）どおり。
