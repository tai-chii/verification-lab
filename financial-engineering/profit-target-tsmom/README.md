## 方法（要点）

- 仮説: H: 建玉の含み益が k·ATR20（k=3）に達したら手仕舞いし次の反転まで待つ利食い規則は、順張りの右裾の利益を削るため純損益 [bp/日] を下げる（差 B−A<0）。
- 定義: A: TSMOM60。B: 利食い k=3（主セル）。k=2・5 は副次。利食い後は合図の符号が変わった日に再建玉。含み益は建玉の約定価格からの終値の差。pnl_bp。
- 測るもの: 年×銘柄の純損益差 B−A [bp/日]（年単位 t）、最大下落の差、利食いで終わった建玉の割合。前後半・群別。
- 帰無: 利食いが発動する日を年内で循環シフト（発動回数を保つ）B=300 → 差の帰無分布 → z。
- 多重比較: 判定は all15 の主セル k=3 の前後半 2 本。k=2・5 と群別は記述。
- 捨てた案: 約3: トレーリング・ストップ（損切りと混ざる）、k を年ごとに選ぶ、利食い後に逆向きで入る案。
- 先行研究チェック: WebSearch 2026-10-10「profit target ATR multiple trend following backtest effect on returns and drawdown」: StockCharts（Arthur Hill 2017）の MA クロスの利食い vs トレーリング、TradingView のスクリプト。 根拠にしない。15 銘柄・前後半・発動日循環シフト帰無で測る形は未確認（条件の穴）。

## 判定（事前固定）

all15 で前後半とも B−A<0 かつ t≤−2 かつ z≤−2 → 支持（利食いは害）。前後半とも t≥2 かつ z≥2 → 逆向きで確定（利食いは益）。それ以外 → 未確定。

## 結果

判定: **未確定**（機械判定どおり。純損益は全群で負の点推定だが統計的に弱い）。
**解釈: Q204 と同じ「保険」型**（純損益は上げないが最大下落は確実に浅くする）。

主セル k=3 all15:

| 期間 | pnl_diff_bp | pnl_t | z | mdd_diff_bp | mdd_t | n_trigger |
|---|---|---|---|---|---|---|
| all | -0.80 | -1.49 | +1.56 | -761.6 | -7.16 | 654 |
| pre (〜2017) | -0.91 | -1.11 | -0.63 | -579.8 | -13.40 | 256 |
| post (2017〜) | -0.70 | -0.94 | +2.48 | -925.3 | -4.93 | 398 |

- 純損益: all15 の点推定は前後半とも負（仮説の向きで利食いは害）だが |t|<2・|z|<2 で事前固定の判定を通らない。前後半で z の符号が逆（pre -0.63／post +2.48）: 帰無分布の中心が期間で動く性質で、点推定の負の向きとは矛盾しない。
- 最大下落: 前後半すべて明確に浅くなる（mdd_diff<0 で t=-5〜-13）。Q204 と同形。
- 利食いで終わる建玉の割合（k=3・全期間）: 17.7%（k=2 で 24.1%、k=5 で 10.5%）。
- 群別（記述）: fx8 post で pnl_diff=+0.74 bp/日・t=3.13（利食いは FX の近年で**助ける**）、trend7 post で pnl_diff=-2.36・t=-1.45（**害する**）。方向が群で分かれる。
- k=2, 5 の副次（all15 all）: pnl_diff_bp は -0.86／-0.68 で k=3 とほぼ同じ。max drawdown の削減幅は k=2 の方が大きい（-917 vs -762 vs -564）＝幅を狭めるほど保険が強く純損益は少し悪化。

多重比較: 事前固定の判定本数は 2 本（all15 の k=3 の前後半）。副次（k=2, 5・群別）は記述扱い。
