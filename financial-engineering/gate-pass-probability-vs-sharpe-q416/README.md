## 方法（要点）

- 仮説: 関門の「最大下落 −6% 以内」は σ 目標 0.5%/日の下では年率シャープ 1.5 を超えないと半分も通らず、現在の探索（単一族・シャープ 0〜0.5）では方法の良し悪しに関係なく通らない。これが本当なら関門は選別ではなく「探索の停止」として働いている
- 測るもの: S∈{0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0} ごとに P(max_dd ≥ −6%)、P(t_pre≥2 かつ t_post≥2)、P(両方＝通過)。P=0.5／0.9 になる S を線形補間。S07 本体の実現値（シャープ・max_dd・t）を併記
- 帰無: 模擬（ブロック再標本・20 日・B=2000 経路。偏差 e＝port−mean に m_S＝S·sd/√252 を足す）。IID 正規版は比較
- 多重比較: 判定は 1 本（S=1.0 と 1.5 の 2 点の P）。ほかは記述
- 先行研究チェック: WebSearch 2026-10-22「probability maximum drawdown exceeds threshold as function of Sharpe ratio proprietary trading firm drawdown limits block bootstrap」: Man Group 'You're fired'（IID 模擬の表）、CME の下落指標のブロック・ブートストラップ、HackerNoon（ブロック長の感度・ブログ＝根拠にしない）。手元の規程（σ0.5%・−6%・14 年・前後半 t）の通過確率は未確認
- 捨てた案の数: 2（年ブロック／σ 目標の掃引）
- 知識の締め切り: Claude の知識の締め切りはおよそ 2026-06
- 委託の確かめ方: なし（Fable 設計 → Sonnet 実行）

## 判定（事前固定）

支持（関門は現実的）: ブロック版で P(通過 | S=1.0) ≥ 0.5。棄却（関門が律速）: ブロック版で P(通過 | S=1.5) < 0.5。ほか → 未確定。IID 版は記述。

## 結果

判定: **棄却（関門が律速）**（機械判定どおり。ブロック版 P(通過 | S=1.5)=0.0375 < 0.5。解釈も同じ）

結果: `results/Q416_result_20261022_155211.json`（48 銘柄・B=2000・20 日ブロック）。点検: data_health の failed なし・missing なし。gaps は 14 銘柄（指数・債券・WTI/BRENT 等の月欠け）→ 除いた 34 銘柄の感度 `sens_exclude_gaps_q416.py`（`results/Q416_sens_nogaps_x.json`）でも同じ判定。

ブロック版（48 銘柄）P(max_dd≥−6%)＝P(通過)（t 条件は S≥1.5 でほぼ満たされるので律速は DD）:

| P(DD ok) | 0 | 0 | 0.002 | 0.038 | 0.19 | 0.42 | 0.65 |

- P(通過)=0.5 になる S は約 2.67（34 銘柄では 2.43）、0.9 になる S は 0〜3 の範囲に無い（3.0 で 0.65）。IID 版はさらに厳しい（S=3.0 で 0.48、P=0.5 は範囲外）。
- 仮説の「S 1.5 超えないと半分も通らない」は控えめで、実際は S≈2.7 要る（実現 σ 0.41%/日で規程の 0.5% より小さい点に注意。σ が目標どおり 0.5% なら DD はもっと深い）。
- S07 本体の実現値: シャープ −0.31・max_dd −34%・t_pre 0.01・t_post −4.0（関門の遠く手前）。
- 含意: 現行の探索（単一族・S 0〜0.5）では方法の良し悪しに関係なく通過確率は 0。S=1.0 の本物の戦略でも 0.2%。関門は DD 条件で選別でなく停止として働く。置き方は taichi が決める（結果を見てから σ 目標を掃引していない）。
- 制約: 模擬の源は S07 の損益（実現 DD −34%・負の平均を偏差で除去）。他の族では DD の形が違いうる。S 刻みは 0.5。
