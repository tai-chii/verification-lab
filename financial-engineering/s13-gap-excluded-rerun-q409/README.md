# Q409 S13 見直し: Q400（月替わり）・Q402（FOMC 偶数週）を穴跨ぎ足を除いて再計算

Q400・Q402 の事後の判断（2026-10-22 14:54・Opus）で「データの穴を跨ぐ足（前の足から 168h 超）が等金額の結果を汚している」とされたため、その足の合図だけを 0 にして同じ SPEC・同じ判定規則で再計算した。

- スクリプト: `kensho_s13_gapfix_q409.py --target q400|q402`（元のスクリプトの `SPEC` と `strategy` を import して包む。冒頭に計画を固定）

- 結果: `results/Q409_Q400_*`・`results/Q409_Q402_*`（13 銘柄すべて ok・failed なし・years_dropped なし・null_degenerate なし・n_tests=2 一致）

- 穴を跨ぐ足を除いた銘柄×年の変化: NLD25 2017 +127.6→+4.6 bp（Q400）、NLD25 2015・2016、US500/USTECH 2012、EUSTX50 2012、HKG33 2013 など。変わったのは gap の足を含む年だけ（`results/*_year_sym_*.csv` の差分で確認）。
- 規程モードはほぼ不変。規程モードは全銘柄の日付の和集合で `POS` を `fillna(0)` するので、他の銘柄が取引している穴の間は位置 0 になり、穴の足のリターンを元々ほとんど取っていなかった（Q402 は数値が一致）。
- **事後の判断の訂正**: Q402 の US500 2011 −165 bp・USTECH 2011 −153 bp は穴跨ぎ足ではない。US500 の 2011 年は 2011-09-22 から 4 本だけ（直後に 2012-01-16 までの穴）で、−165 bp は 2011 年 9 月末の実際の下げの 3 本の平均。行数で平均されるので全体への寄与は小さく、穴跨ぎ足（2012-01-16・+15.0%）は 2012 年側にある。
- 副設定（記述）: Q400 の副窓(−4,+3) は穴除外で全期間 t_year 1.97（net 0.96 bp）。判定には使わない。Q402 の extra（偶数週 2.48・奇数週 2.91 bp/日）は gap 行を含む素の平均で、偶数週が高い形はやはり出ない。

判定: **棄却**（両方。Q400 は等金額の全期間 z=−0.06<1、Q402 は z=−1.65<1。事前固定の棄却条件に当てはまる。機械判定と同じ）

**解釈**: Q400 の後半の正（z 2.07）は NLD25 の穴跨ぎ足 1 本が作っていた。除くと前後半とも帰無の範囲。Q402 は元の判定（棄却）が正しく、事後の判断の「未確定へ直す」は取り消す。2010 年以後の 13 指数では、月替わり 4 本・FOMC 偶数週のどちらも規程つきで使える暦効果ではない。
