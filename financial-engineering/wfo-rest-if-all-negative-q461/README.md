# Q461 選び直す WFO で直前窓の全候補が負なら休むと、常に最良を選ぶより標本外は良くなるか

事前登録: `検証/学問/金融工学/知識/文献/アイデア候補.md` の Q460-C3 の行（接続 Q460・2026-10-22）。出典: ブログ Zenn 2026 hiro-2（hiro_algo の WFO は「全候補マイナスでも最もましな 1 つを選ぶ」）。設計・実行・解釈は Opus（2026-10-22 21:53〜、ループ）。計画はスクリプト冒頭に固定。

- スクリプト: `kensho_wfo_rest_q461.py`（fe_core の土台＋Q177 の `_walk` を f=21 で再利用。約 5 秒）
- 結果: `results/Q461_result_20261022_215532.json`、`results/Q461_cells_20261022_215532.csv`（銘柄×年の A・B）
- データ: 15 銘柄 D1_fromH1、封印 time<2024-07-01（標本外 2011〜2024 上半期の 14 年）

## 方法（要点）

- 候補 TSMOM L∈{5..300}（60）、選択窓 756 日、21 日ごとに選び直し、段階 1 コスト（切替・休む／戻るの |Δpos| も課金）。
- A＝常に窓内平均純損益が最大の L。B＝その最大値 ≤0（全 L が負）なら次の 21 日は 0。
- 銘柄×年の平均 [bp/日] → 年ごとに銘柄平均 → B−A の年単位 t（前後半 〜2016／2017〜）。
- 帰無: 休む日の印を銘柄×年の中で循環シフト B=300 → B'−A の分布の 95 点。
- 判定（事前固定）: 休んだ日 <2% → 対象なし。支持＝t≥2・前後半とも正・帰無 95 点超。棄却＝|t|<1 または前後半で符号が割れる。ほか未確定。

判定: **棄却**

**解釈: 全候補が負なら休む規則は、15 銘柄の日足 TSMOM の選び直し WFO では純損益も最大下落もほとんど変えない（B−A −0.02 bp/日・t −0.41・前後半で符号が割れる）。そもそも 756 日窓で全 60 候補が負になるのは 3% の日だけで、その大半が USDCHF。hiro_algo の「全候補マイナスでも選ぶ」は、少なくともこの設計では成績悪化の主因ではない。** FX8 では休むと最大下落が 216 bp 浅くなるが、帰無（同じ長さの休みを年内の無作為な位置に置く）より悪く、休む位置に情報は無い。
