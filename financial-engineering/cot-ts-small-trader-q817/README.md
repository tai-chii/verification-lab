## 方法（要点）

- 定義: 小口ネット = −(投機筋ネット＋実需ネット)。z = 156 週（最低 104 週）。持ち高 = −clip(z, ±2)÷2
- 枠: Q593 と同じ対応表（17 銘柄）と約定の決まり: 報告日（火曜）+6 日以降の最初の営業日の終値で持ち替え（公表は金曜）。銘柄ごとに年率 10% にそろえて銘柄数で割る・片道コストは段階 1 の仮置き（FX 1bp・指数 2〜3bp・金属 2〜8bp・エネルギー 5〜10bp）・スワップなし・評価 2012-01〜2024-06・前後半の境 2017-01-01
- 帰無: 合図の週を循環シフト（26 週以上・B=500）。統計量はコスト後の日次平均
- 先行研究チェック（2026-11-24・検索語「COT commercial hedgers small traders non-reportable positions extreme predict futures returns time series」・同じ族の案とまとめて 1 回）: 「小口は逆指標」という通説と、非報告は残差であり小口と呼べるか疑う論文（Sanders・Irwin・Merrin 2009 JARE）がある。2012〜2024-06 の 17 銘柄・公表後の約定では未確認（追試）
