- **問い**: CFTC 建玉の小口（報告義務なし）のネット÷建玉の 156 週 z の逆張り（銘柄ごと・時系列）は、コスト後に残るか
- **出典**: Wang (2001)／Sanders, Irwin, Merrin (2009) 小口は逆指標か／Q593（横断・棄却）の時系列版

- **定義**: 小口ネット = −(投機筋ネット＋実需ネット)。z = 156 週（最低 104 週）。持ち高 = −clip(z, ±2)÷2
- **測り方**: Q593 と同じ対応表（17 銘柄）と約定の決まり: 報告日（火曜）+6 日以降の最初の営業日の終値で持ち替え（公表は金曜）。銘柄ごとに年率 10% にそろえて銘柄数で割る・片道コストは段階 1 の仮置き（FX 1bp・指数 2〜3bp・金属 2〜8bp・エネルギー 5〜10bp）・スワップなし・評価 2012-01〜2024-06・前後半の境 2017-01-01
- **帰無**: 合図の週を循環シフト（26 週以上・B=500）。統計量はコスト後の日次平均
- **判定（事前固定）**: 支持（フォワード候補）: コスト後の日次平均 > 0 かつ NW t ≥ 2.0 かつ 前後半とも平均 > 0 かつ 帰無 z ≥ 2.0。棄却: 全期間の日次平均 ≤ 0 または 帰無 z < 1.0。それ以外: 未確定。
