## 限り
- 価格は配当でも調整されているので、古い日付の「財務÷価格」は配当の累積分だけ大きめに出る（全銘柄に同じ向き・高配当の銘柄がやや割安に見える）。生の株価が手に入れば直せる。株主資本・年次フローのタグ優先は事前登録どおり（end が新しいタグを採り、同じ end なら優先順）。
- 生存バイアスあり（今の構成の 861 銘柄が SEC 側の宇宙・適格は売買代金上位 800 ∧ 財務あり）。
- 1 年前の値は「現在の値の end より 300〜430 日前の end のうち最新（その end の最初に出た値）」と読んだ（事前登録は「end が 300〜430 日前」とだけ書く）。
- 分割補正の F は「株数の観測日 end より後の分割の積」（`sec_pit.factor_at_end`）。事前登録の F(t)（`split_factor`）と違うのは、観測日 end〜t の間に分割があるとき（F(t) だと株数が分割前・価格が分割後でずれる）だけ。事象の日付は分割後の最初の観測の end。
- 株数は XBRL の提出時のデータに誤り（千株単位の誤記、後の提出での遡及修正）があり、一部の分割は検出できない（例: AAPL 2014 の 7 対 1 は 10-Q の千株誤記で比が整数比に合わず未検出）。また 1.5 倍付近の増資・合併（ADI 2021 のマキシム買収など）は 3 対 2 の分割と区別できず補正される。事前登録の規則どおりで変えていない。
- 株数の系列は銘柄ごとに 1 本に固定（CommonStockSharesOutstanding の end が 8 本以上あればそれ・無ければ Weighted…Diluted）。
- 本物の facts.parquet での分割検出のみ読むだけで確かめた（861 銘柄で 317 事象）。本番の計算は走らせていない。
