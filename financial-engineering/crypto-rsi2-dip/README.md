## 方法（要点）

- 仮説: Connors 型: t の終値で RSI(2)<lo かつ close>SMA200 なら翌日から買い、保有中に close>SMA5 となった日の終値で手仕舞い（空売りなし）。11 通貨の年単位の日平均純損益 [bp]（往復 30bp）が前半（〜2021）・後半（2022〜）とも >0 で、合図の循環シフト帰無より高い
- 測るもの: 年単位の日平均純損益 bp（コスト 0 と往復 30bp）、年単位 t、束ねた t、Sharpe（365 日）、最大下落、露出。記述: lo=5/20
- 帰無: 通貨ごとに合図列を循環シフト（min_shift=60）B 回 → 束の年単位 bp の帰無分布 → z・perm_p・Holm（前後半 2 本）
- 多重比較: 判定は 2 本（Holm で補正）。ほかの設定・群は記述
- 先行研究チェック: WebSearch 2026-10-16・standard・検索語 "Connors RSI(2) mean reversion strategy cryptocurrency daily backtest bitcoin altcoins transaction costs"。見つかったもの: ProRealCode の RSI-2 戦略、Substack の RSI2 バックテスト、TradingView の Connors RSI（いずれもブログ・株価指数中心）。未確認: 暗号資産の複数通貨で RSI2 押し目買いをコスト込み・前後半・合図の循環シフト帰無で測った研究は見当たらない（移植）。ブログは根拠にしない
- 捨てた案の数: 約4: 手仕舞いを RSI2>70 にする版（Q271 型・掃引を増やさないため記述にも入れない）、SMA200 フィルタなし、高ボラ局面限定（Q271 の続きで別案）、H4 版
- 知識の締め切り: Claude の知識の締め切りはおよそ 2026-06。データは 2017-05〜2026-09（2026-07 以降は締め切り後）。規則は固定で相場観は使わない
- 委託の確かめ方: 設計とコードは Opus（2026-10-16）。実行と記録は Sonnet（怪しければ escalate）。結論ではなく JSON のパス・前後半の bp・z・p_holm を返させ、本体が確かめる

## 判定（事前固定）

既定の 3 分岐: main（lo=10）の前後半ともコスト後 bp>0 かつ Holm 補正後 p<0.05（循環シフト帰無の perm_p）→ 支持。全期間の z<1 → 棄却。それ以外 → 未確定
