## 読み
1. **コスト負けは解消した**（1 回の値幅を広げたのでコストは 0.03〜0.09 bp/日）。残った問題は、コスト前の稼ぎが本物の信号でないこと。
2. **F1 の見かけのプラスは相場固有の戻りやすさではない**。ボラと年の動きを保って順番を壊した系列のほうが稼げる（+0.26）。年の動きは帰無に残るので、複数年の水準への回帰は測れていない。測れたのは「年の中の経路は格子に有利ではない」まで（Q581 と同じ結論）。
3. F1 は 2017〜2024 の 8 年すべてプラス（+0.2〜+1.7%/年）だが、2013 年の −4.0% で前半が負ける。「小さく勝って、たまに大きく負ける」形そのもの。レンジ通貨ペアでも同じ。
4. F2 の稼ぎはスワップだけ。NZDJPY・AUDJPY は良いが、銘柄を選ぶのは事後の選択。
5. F3 は「押し目で買う」形にしても順張りの負けを減らせるだけで、プラスにはならない。

## 確かめと限界
- **クロス 5 本は組から合成**（Dukascopy の応答が遅く、本物の H1 は約 6 時間かかるため）。合成では足の中の高安が無いので実体だけで約定を判定した。本物のある EURGBP との相関は 0.988 だが平均は +0.10 と −0.16 で、**実体だけの扱いは成績を低く見積もる**。
- 本物の高安がある FX 8 本で比べると、実体だけは平均を 0.32 bp 下げ、帰無も 0.44 bp 下げる（`check_wick_q591.py`）。本物の高安でも z −1.63（実体だけ −0.29）で、**F1 を本物のデータに替えても平均は上がるが z<1 の棄却は変わらない見込み**。本物の H1 のクロスでは走らせていない（候補が出なかったので取得は途中で止めた・AUDNZD の一部だけ `_raw` に残る）。
- スワップは金利差からの近似で XM の実値ではない。F1 はスワップ抜きでも PF 1.06・t 1.41 で関門に届かない。
- 1 回目の計算に誤りが 2 つあった（帰無の発散・指数のスプレッドの桁）。直して走らせ直し、判定は同じ。詳細は事前登録の末尾。
- エンジンの確認: 経路と無関係にヒゲを足した合成データでは偽のプラスが出た（F2 +0.38±0.08・F3 +0.20±0.04 bp/日）。本物の経路から作った OHLC では 3 型とも標準誤差の 1.5 倍以内。
