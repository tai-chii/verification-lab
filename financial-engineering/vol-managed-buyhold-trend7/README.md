## 方法（要点）

- 仮説: w[t]=min(σ̃[t]/σ20[t], 2)。σ20 は t までの 20 日の日次リターンの標準偏差、σ̃ は t までの σ20 の拡大窓の中央値（先読みなし）。重みは 5 本ごとに更新し間は持ち続ける。t の終値で決め t+1 から保有（買いのみ）。7 銘柄の等加重束の年率シャープ（段階1コスト後）は、前後半とも買い持ちより高く、銘柄ごとに w を循環シフトした（重みの分布と平均を保つ）帰無のシャープより z≥2 で高い
- 測るもの: 等加重束の年率シャープ（252）を調整・買い持ち・帰無で前後半に。記述: 銘柄ごとのシャープ差、最大下落、平均の重み、売買回転
- 帰無: 銘柄ごと・期間ごとに w 列を循環シフト（k∈[60, n−60]）B 回 → 束のシャープの帰無分布 → z
- 多重比較: 判定は 2 本（前後半の両方を要求する交差のため Holm なし）。ほかの設定・群は記述
- 先行研究チェック: WebSearch 2026-10-16・standard・検索語 "volatility-managed portfolios commodities equity index futures bitcoin buy and hold Sharpe out-of-sample Moreira Muir replication"。見つかったもの: Cederburg・O'Doherty・Wang・Yan 2020（JFE・103 系列の標本外で多くが勝てない）、Strathclyde の商品先物のボラ管理（Journal of Futures Markets 2021）、Lehigh の COWY 論文。未確認: 金・銀・原油・株価指数 CFD・BTC の 7 銘柄束で、重みの分布を保つ循環シフト帰無に対してタイミングの価値を前後半で測った形は見当たらない（移植）
- 捨てた案の数: 約4: σ²（分散）の逆数（Moreira–Muir 原典。上限に張り付きやすいので σ に）、窓 60 日（Q205 と同じで新しさが無い）、FX8 も含める（買い持ちの向きが恣意的）、Parkinson σ（Q207 系と重なる）
- 知識の締め切り: Claude の知識の締め切りはおよそ 2026-06。データは 2008〜2026-06（油・指数は 2011-09〜）で締め切り前。規則は固定で相場観は使わない
- 委託の確かめ方: 設計とコードは Opus（2026-10-16）。実行と記録は Sonnet（怪しければ escalate）。結論ではなく JSON のパス・前後半の Sharpe 3 本（調整・買い持ち・帰無中央値）と z を返させ、本体が確かめる
