## 方法（要点）

- 問い: taichi のチャット（2026-10-29）「MA 2 本を 10〜200 で総当たりして指標の分布を出せば bot や論文になるか」「各指標 TOP5 を動かす bot は強いか」を数字で答える。
- 格子: 短期 10〜190・長期 20〜200・10 刻み・S<L の 190 組。SMA。常時ドテン、利確・損切りなし、合図の足の終値で約定（土台の pnl_bp）。段階 1 のコスト。
- 2 種の損益: bp 損益（年単位 t 用）と、ATR サイズつき損益（1 回 0.5%・仮のストップ 2×ATR20・レバ上限 3）→ 複利の資産曲線から 年率 Sharpe・最大 DD・カルマー・月次σ・最悪月・負け月割合、取引単位で PF・勝率・月間回数。
- (A) スペック §1 合格 = Sharpe≥2 かつ 最大 DD≤10% かつ 月次σ≤3.5%。再現合格 = 前半（<2017）と後半（≥2017）の両方で合格。15 銘柄の合計を数える。実運用水準（Sharpe≥1.5・DD≤20%）は記述。
- (B) 銘柄ごとの 190 組の前後半 Sharpe の Spearman → 中央値（記述）。
- (C) 銘柄ごとに前半 Sharpe 上位 5 組の等ウェイト − 190 組の等ウェイト（bp/本）を後半の年×銘柄 → 年ごとに銘柄平均 → 年単位 t。カルマー上位 5 は記述。
- 帰無: 銘柄ごとに 190 組の建玉行列を**同じ k で循環シフト**（組どうしの相関・自己相関を保つ・min_shift 250 本）して同じ手順を B=200 回 → (A)(B)(C) の z。
- 台地（記述）: `heat` CSV の S×L の中央値 Sharpe（前・後・全）、合格組の S・L の上位 20。
- 多重比較: 判定は D1・H4 の (C) の t と z の 4 本と (A) の 2 本。ほかは記述。
- 先行研究チェック: WebSearch 2026-10-29「moving average crossover parameter grid multi-asset out-of-sample rank correlation data snooping false discovery trend following」: arXiv 1901.01751（MA と モメンタムの関係）、arXiv 2504.10914、FMPM 2023（s11408-023-00433-2・MA 規則とコスト）、CXO Advisory「trend indicator similarities」（ブログ・根拠にしない）。15 銘柄×D1/H4 で「月次スペックの合格率とその帰無」「前半 TOP5 の等ウェイトを後半で等ウェイト全体と比べる」形は未確認（横展開＋条件の穴）。手元では `ma-cross-eurusd/` が EURUSD/USDJPY H4 で 2 本 SMA/EMA 約 3 万組の順位相関（SMA 2 本 −0.36／−0.19）と Reality Check p（0.37〜0.59）を出しており、本案はその 15 銘柄・D1 込み・スペック基準版。
