## 方法（要点）

- 仮説: 同じ合図規則でコストを {0, 0.5, 1, 2, 3}× 段階1 の 5 本に広げ、全期間の bp_net の正負を見る。main_param=1×（段階1そのもの）
- 測るもの: 5 水準の全期間 bp_net・t、ゼロ跨ぎの倍率、取引回数、年単位の値動き
- 帰無: 合図の循環シフト（min_shift=120）B=500 → main=1× の年単位 bp の帰無。帰無は main でのみ計算（コスト倍率は帰無と独立）
- 多重比較: 判定は 2 本（Holm で補正）。ほかの設定・群は記述
- 先行研究チェック: Hurst et al. (2017) は TSMOM のコスト余裕を 2〜4× とした。本件は TREND7 封印前の実測
- 捨てた案の数: コスト 5× 以上（現実のスプレッド拡大の目安を超える）
- 知識の締め切り: Claude の知識の締め切りはおよそ 2026-06。規則は固定で相場観は使わない
- 委託の確かめ方: なし

## 判定（事前固定）

3× でも bp>0 → 支持（余裕大）。2× で bp>0・3× で bp≤0 → 支持（限定）。1× で bp>0・2× で bp≤0 → 未確定（きつい）。1× で bp≤0 → 棄却

## 結果

実行日: 2026-10-21。B=500、TREND7 7 銘柄すべて読み込み成功。

| コスト倍率 | bp_net（全期間） | t_year |
|---|---|---|
| 0× | +2.99 | 1.49 |
| 0.5× | +2.73 | 1.36 |
| 1× | +2.46 | 1.23 |
| 2× | +1.92 | 0.97 |
| 3× | +1.39 | 0.70 |

main_param（1×）前後半: 前半（2012-2017）bp_net=+0.64 bp（p_holm=0.375）、後半（2017-2024）bp_net=+3.59 bp（p_holm=0.208）。全期間 p_perm=0.104（Holm 前、z=1.33）。null_degenerate=False。data_health: gaps 4 件（すべて 2012-02-01 以前、実測に影響なし）。

判定: **支持（余裕大）: 3× 段階1コストでも全期間 bp_net>0（+1.39 bp）。ただし全期間 p_perm=0.104 で統計的有意ではなく、前半期（2012-2017）の余裕は小さい（+0.64 bp）。コスト余裕の大きさの主張は成立するが、戦略自体の有意性は弱い。**

解釈: **未確定（弱い支持）**: コスト余裕は 3× 以上あると示せたが、母数（t_year=1.23）が弱く前半期はほぼコスト0と同等の粗利。Hurst et al.（2017）の「2〜4×」という先行研究と整合する範囲に収まる。
