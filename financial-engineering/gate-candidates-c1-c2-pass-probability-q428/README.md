## 方法（要点）

- 仮説: C1（σ 0.25%/日）は最大下落の分布を半分の深さに縮めるので、年率シャープ 1.5 の戦略の過半を通す（現行 4%）。C2 を文字どおり「実現の年率 σ × 0.75」で置くと、σ 0.5%（年率 約 8%）では −6% とほぼ同じで緩和にならず、実現 σ が目標を下回る戦略にはむしろ厳しい。★ C の実質の選択肢は C1 の σ の値で、C2 は定義を直さないと使えない
- 変種（事前固定）: current（σ 0.5%・−6%）、C1_025（σ 0.25%・−6%・**判定に使う**）、C1_035（σ 0.35%・−6%）、C2（σ 0.5%・≥ −0.75×経路の実現年率 σ）。sym_cap・レバ・日次停止は全変種で同じ
- 測るもの: 変種 × S∈{0, 0.5, 1.0, 1.5, 2.0, 2.5, 3.0} ごとに P(dd ok)・P(t_pre≥2 かつ t_post≥2)・P(通過)・dd 中央値、1 年到達率（暦年の年初からの累積損益が −6%／−10% 以下になった (経路, 年) の割合＝1 口座 1 年あたりの失格率）。P=0.5／0.9 になる S を線形補間。各変種の S07 本体の実現値
- 帰無: 模擬（20 日ブロック再標本・B=2000 経路。偏差 e＝port−mean に m_S＝S·sd/√252 を足す）。IID 正規版は比較
- 多重比較: 判定は 1 本（C1_025 の S=1.5 と 2.0 の 2 点の P）。ほかの変種・到達率は記述
- 先行研究チェック: WebSearch 2026-10-22「proprietary trading firm drawdown limit probability of breach as a function of Sharpe ratio volatility target block bootstrap simulation」: Man Group 'You're fired'（IID 月次・10 年・シャープ 0.5 で 2σ 下落に 43%）、Mannheim 大 madoc 72376（Efron の IID ブートストラップは MDD を過小評価、定常ブートストラップが頑健）、CME「portfolio management with drawdown based measures」、Substack 2 本（ブログ＝根拠にしない）。プロップの規程（σ 目標の変種・初期資金基準の失格率）を手元の損益の形で測ったものは未確認
- 捨てた案の数: 3（過去 16 戦略の結果を C1/C2 で当て直す＝事後の掃引／σ の細かい掃引＝値は人が決める／S16 合成を源にする＝前半に暗号が無く形が偏る）
