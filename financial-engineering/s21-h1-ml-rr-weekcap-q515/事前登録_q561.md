# 事前登録 Q561 — RF の四半期 AUC（Q560）は S21 WF の同じ四半期の損益と対応するか

- 作成: 2026-10-28 08:05（Fable・Q560 の続きの案 → taichi「進めて」）。**S21・フォワードは変えない。** 学習はしない。既存の結果（Q560 の地図・Q555 の売買表）を突き合わせるだけ。設計とコードまで。
- 問い: 同じ特徴量で測った「局面の難しさ」（RF の学習外 AUC・コスト抜き）が低い四半期は、S21 の 1 件あたり R も低いか。対応するなら、地図は S21 の負けの切り分けに使え、先読みも効くなら規模調整の材料になる。
- 先にある証拠（結果を見る前に書く）: Q560 で四半期の AUC は本物の散らばり（z 6.3）を持つが、ラグ 1 自己相関は 0.1。Q555 で WX の月次 R はプラス月 66%・日次 t 4.8。S21 の期待値は最上位五分位に集中（Q515）し、RF の AUC は全足で測るので、同じ四半期でも対応は弱めに出るはず。→ 事前の見込み: **ρ_q は正だが 0.2〜0.4 程度、ρ_lag は 0 近辺**。

## データ
- `results/result_q560.json` の `per_q_auc`（15 銘柄プールの四半期 AUC）と `results/cells_q560.csv`（セル AUC）。
- `results/trades_q555.csv.gz` の腕 **WX**（拡大窓・毎月学習し直し。Q555 の基準腕）。腕 **Y**（年 1 回＝今の S21 の運用）は記述。
- 重なる期間 **2016Q4〜2025Q3 の 36 四半期**。売買は入った足の四半期で集める。

## 物差し
- 主 ρ_q: 四半期 AUC と四半期の **1 件あたり平均 R** の Spearman（36 点）。
- 副 1 ρ_cell: セル AUC とセル（銘柄 × 四半期・WX の売買 ≥10 件）の 1 件あたり R の Spearman。
- 副 2 ρ_lag（先読み）: **前の**四半期の AUC と今の四半期の 1 件あたり R の Spearman（35 点）。
- 記述: 合計 R 版の ρ・AUC 上位 1/3 と下位 1/3 の四半期の平均 R・腕 Y で同じ 3 つ・四半期の循環シフト 35 通りに対する観測の順位。

## 帰無
- 四半期（セル）の並べ替え B=5000。片側 p =(1+#{帰無 ρ ≥ 観測})/(B+1)。
- 頑健性（記述）: 四半期の循環シフト（1〜35）で得た ρ のうち観測以上の割合。

## 判定（事前固定・変更禁止・多重比較 3 本〔ρ_q・ρ_cell・ρ_lag〕に Holm）
- **支持（地図は S21 の損益と対応する）**: ρ_q ≥ 0.3 かつ Holm 後 p < 0.05。
- **棄却（対応しない）**: ρ_q ≤ 0。
- **未確定**: それ以外。
- ρ_lag が Holm 後 p<0.05 なら「先読みにも使える」と記述に足す（判定には使わない）。ρ_cell も記述。
- 試行の数え方: 地図の検証 3 本目。捨てた案: Q559（コスト込み）の AUC を使う・月次で見る・日次 t と対応させる — の 3 つ。
