- 平均保有 14.8 日（時間切れ 0.3%）。**保有コストが損失の約半分**（−0.121 → −0.066）
- 保有コストを除いても負けで、しかも「条件なしで入る」より悪い銘柄群が多い＝日足ではモデルの選び方が当たっていない（逆に働いている）
- 条件なしでも保有コストを除いて負けるのは、日足 1 本の中で SL と TP の両方に触れた日を SL 扱いにした保守的な近似の影響を含む（H1 では足が細かいので小さい）
- 債券・暗号は特に悪い（件数は少ない）

## 結論
- 同じ ML・同じ入り方は、日足では通用しない。H1 の優位は「H1 の値動きの短い先読み」に依っていて、日足へ時間軸を伸ばすと消える
