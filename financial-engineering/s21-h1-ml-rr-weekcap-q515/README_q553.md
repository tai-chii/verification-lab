## 原因の切り分け（記述）: **弱くなったのは FX 主要 7 本と売りだけ**
| 銘柄群 | 前半（2014〜19）平均 R | 後半（2020〜25） | 粗利 前→後 | コスト 前→後 |
|---|---|---|---|---|
| **FX 主要 7 本** | **+0.077** | **−0.028** | 0.152 → 0.072 | 0.075 → 0.100 |
| 円 3 本 | +0.065 | +0.053 | 0.110 → 0.129 | 0.046 → 0.075 |
| 指数 4 本 | +0.051 | +0.056 | 0.167 → 0.119 | 0.116 → 0.063 |
| 金 | +0.058 | +0.013 | 0.185 → 0.103 | 0.127 → 0.090 |

- FX 主要の合計は前半 +592R → 後半 **−160R**。件数の割合も 51% → 36% に減った。FX 主要を除いた 8 本（円 3・指数 4・金）の平均 R は前半 +0.060・後半 +0.051 で、**ほとんど落ちていない**。
- 買い +0.072 → +0.045、**売り +0.065 → −0.005**。
- FX 主要は粗利が半分になり（当たらなくなった）、同時にコストが 3 割重くなった（損切り幅に対してスプレッドが広がった＝値幅が小さくなった）。

## 読み
- S21 のエッジは全体として消えてはいない（12 年すべてプラス・円と指数は前後半で同じ水準）。「最近の弱さ」の中身は、**FX 主要 7 本の悪化**（とそれに伴う売りの悪化）。
- ただし「FX 主要を外す」は結果を見てからの選択（多重比較の外）なので、**今は S21 を変えない**。前向きの記録で確かめる → Q554（前向き予約）。
