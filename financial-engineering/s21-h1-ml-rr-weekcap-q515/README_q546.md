## 判定（事前登録）: **3 年もつ**（ただし稼ぎは約 2/3・下落は深い）
比べる年 = 2016-10〜2025-09 の 9 年（3 つの古さがそろう年）

- 判定の式: 3 年目の t 2.97 ≥ 2 かつ 合計 R 0.66 倍 ≥ 0.5 → 「3 年もつ」。
- 年ごとの差（3 年目 − 1 年目の平均 R）: 平均 −0.016R・t −2.01。2 年目 −0.018R・t −2.83。**古いモデルは一貫して少し弱い**（劣化の閾値 0.5 倍の内側）。

- 弱さは 2021〜2023 年度に集まる: この時期は学習し直したモデルだけがプラスで、古いモデルはマイナス。局面が変わった年は、学習し直しがあった分だけ損を避けていた。

## 読み（運用への意味）
- フォワードの凍結モデル（2026-09-30 まで学習）は、2〜3 年使っても**エッジは残る見込み**。ただし期待値はバックテスト（毎年学習し直し）の **約 2/3**（年 +120R → +80R 前後）で読むのが安全。
- **停止線とのずれ**: 運用規程の停止線 −130R は毎年学習し直す形の最大下落（−129〜−134R）から決めた。凍結モデルの 3 年目の最大下落は −315R、2 年目は −197R。**エッジが残っていても、凍結のまま 2〜3 年目に入ると停止線に触れうる**。停止線を変えるか、年 1 回の学習し直し（別 ID で凍結し直し）を入れるかは taichi の判断（要対応 2026-10-27 16:00 ★）。
- 1 回のリスク量 0.04%（想定最大下落 −260R から）も、凍結 3 年目の −315R の前では余裕が小さい。
