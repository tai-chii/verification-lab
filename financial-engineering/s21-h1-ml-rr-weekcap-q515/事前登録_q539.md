# 事前登録 Q539 — S21 のコストの厳しさの確認（スプレッド 1.5・2・3 倍・損切りの滑り）

- 作成: 2026-10-26 20:55（Opus・taichi「進めて」）。**新しい案ではない。S21 の規則・凍結したモデル・フォワードの停止線は変えない。** 2027-04 の小額実弾の判断の前に、S21 がコストにどこまで耐えるかを知る。
- 土台: S21 候補形（Q533 D2＋Q534 E1）の WF 11 年の売買記録 `results/trades_q534_E1.csv`（15 銘柄・28,888 件・2014-10〜2025-09）。学習はし直さない。
- 方法: 各売買の R はすでに Bid/Ask の実測で計算されている（買いは Ask で入り Bid で出る、売りは逆）。そこで売買ごとに「スプレッドの分の R」c = (入った足の始値のスプレッド ＋ 出た足の終値のスプレッド) ÷ D（D = 1.5×ATR24・決めた足の値）を H1 データ（`market_data/H1`・Q515 と同じ load）から出し、R_k = R − (k−1)·c とする。出た足のスプレッドは終値の値で近似（足の中で決済した時刻のスプレッドは無い）。
- 滑り: 損切り（R ≤ −0.95）と窓の決済に、さらに出た足のスプレッド 1 本分を足す（R − s_出 ÷ D）。

## 測るもの
- k ∈ {1, 1.5, 2, 3}、各 k に滑りあり・なし。1 件あたり平均 R、日次 t（決済日ごとの R の合計・その期間の平日すべて〔売買の無い日は 0〕）、11 年合計、最大下落、プラスの年の数。
- 損益分岐の倍率 k* = 1 + 平均 R ÷ 平均 c（平均 R が 0 になる倍率）。銘柄群ごと（ドル円以外の FX 主要・クロス円・指数・金）にも出す。
- k=1 の日次 t が Q534 の 4.72 と近いか（日次の集計の違いの確認。大きく違えば集計を README に書く）。

## 判定（事前固定）
- **2 倍に耐える**: k=2（滑りなし）で平均 R > 0 かつ 日次 t ≥ 2。**3 倍に耐える**: k=3 で同じ。
- **滑りにも耐える**: k=1＋滑りで平均 R > 0 かつ 日次 t ≥ 2。
- どの結果でも S21 は変えない。損益分岐の倍率を、Fintokei の実際のスプレッド（Dukascopy より広い可能性）と比べる材料にする。
