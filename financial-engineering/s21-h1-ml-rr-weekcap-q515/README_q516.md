## 読み方
- 日足 ZigZag++ の向きで方向を縛ると、Q515 でモデルが取っていた「向きに逆らう側の当たり」（押し・戻りの逆張り成分）を捨てることになる。週上限を外した分は件数が増えただけで、1 件あたりの質が下がった
- 2 つの変更（上限撤廃・方向固定）を同時に入れたので、どちらが効いたかは切り分けていない
