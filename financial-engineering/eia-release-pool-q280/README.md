## 方法（要点）

- 仮説: Q269 と同じ H: E[sign(r_0)·r_{1..3}]=0。
- 定義（Q269 と同じ）: NY 時刻 America/New_York、r_0 = 10 時台、r_1..3 = 11〜13 時台の和。y=sign(r_0)·r_1..3 [bp]。
- 発表日: 毎週水曜。その週（Mon-Fri の ISO 週）の Mon/Tue/Wed に `USFederalHolidayCalendar` の祝日があれば Thursday にずらす（111 日が Thursday・645 日が Wednesday）。原典とのずれ: Monday 5pm 等の個別シフトは反映しない。
- 統計量: 2 銘柄プール。(year, sym) セル → 年平均 → 全期間平均（年単位 t も同じ重み）。
- 帰無: sign(r_0) を日で ±1 無作為に付け替え B=2000。
- 多重比較: 主判定はプールの全期間（1 本）。前後半・銘柄別は記述。
- 捨てた案: 約2（Fisher 結合・原典一覧の精密手入力）

## 判定（事前固定）

- プール全期間 |z|<2 かつ 2 銘柄とも |z|<2 → 支持
- プール全期間 |z|≥2 かつ 2 銘柄とも前後半で同符号で |z|≥2 → 棄却（向きを書く）
- それ以外 → 未確定

## 結果

- 実行: 2026-10-13 02:44（Opus /lab・macnote）。B=2000・SEED=20261013・分割年2017。
- 発表日 CSV: 756 日（645 水曜 + 111 木曜シフト）。マッチした event 行: 1471（WTI 737・UKOIL 734・Q269 の 732+727 とほぼ同数）。
- **判定: 未確定**。
- プール（WTI+UKOIL）: 全 n=1471・y=8.35 bp・t=2.31・**z=2.49**（事前閾値 2 を超える）。pre t=2.60・z=2.46。post t=1.27・**z=1.35**。
- WTI 全: n=737・y=12.4 bp・t=2.68・**z=2.42**（Q269 の z=1.89 から上昇）。pre z=2.08・post z=1.66。
- UKOIL 全: n=734・y=4.3 bp・t=1.15・**z=0.94**。pre z=1.47・post z=0.26。
- 解釈: Q269 の毎週水曜近似が検出力を落としていた可能性が示唆される（WTI だけで z=1.89→2.42）。プール全期間は閾値を超えるが、UKOIL と post-half で |z|<2 なので「棄却」の事前条件は満たさない。方向はプール・銘柄別・前後半すべて正で揃っており「反転」ではなく「継続」側だが、強さが時間とともに弱まり UKOIL では小さい。コスト（WTI 片道約 7.5 bp 往復）に対し y=12.4 bp は 2017 年以降は y=11.0 bp・t=1.65 で統計の裏付けが弱く、段階2 への昇格は低優先のまま。
- 多重比較の脚注: Q269＋Q280 の2回判定とみなしても Holm で WTI 全の pct=0.99 → 2×(1−0.99)=0.02 以下にはならず、プール pct=0.9945 → 2×0.0055=0.011 で p<0.05 だが、事前の棄却条件（前後半＋銘柄別）を満たさないので「未確定」のまま。
- 判定: **未確定**（**解釈: WTIで継続側・時代効果と銘柄間の揃いが条件を欠く**）
