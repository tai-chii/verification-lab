## 方法（要点）

- 合図: 直前 252 日の対数リターンの符号（Q218 と同じ）を 21 日ごとに読み、次の読み日まで持つ。片道コスト段階1。セル＝(銘柄, 読み日) の翌 21 日の純損益合計 [bp]。
- 滑らかさ: R²＝直前 90 本の対数終値の時間回帰の決定係数。FIP＝sign(直前252日リターン)×(下げ日の割合−上げ日の割合)（252 本）。銘柄内の過去の読み日の中央値（拡張窓・当日除く・最低 12 回分）より R² が高い／FIP が低いセルを「滑らか」。
- 測るもの: 年ごとに全銘柄プールで mean(滑らか)−mean(非滑らか) [bp/月]、年単位 t。前半 2008〜2016（実際は 2010〜2016 の 7 年）／後半 2017〜2026-06（10 年）。2022〜 は記述。
- 信号の強さとの区別（記述・事前固定）: 強さ s=|ret252|/(σ60√252) の高低差、強さの高低それぞれの中での差の等ウェイト平均（強さ層別）、Spearman。
- 帰無: R²・FIP の系列を銘柄内で循環シフト（最小 42 日）B=1000。銘柄ごとの k と全銘柄共通の k（Q320 の規則）の 2 通り。z は記述。
- 捨てた案の数: 約 5（傾き×R² の合成点・FIP を 90 本で数える・3 分位・毎日のリバランス・2022〜を判定に入れる）。
- 知識の締め切り: Claude はおよそ 2026-06。データも 2026-06 まで＝全期間が締め切り以前。
- 委託の確かめ方: コード・実行・一次の解釈は本体から委託されたサブエージェント（Opus）。本体は JSON の数値を照合する。
- 事前登録からの変更点: (1) FIP の割合を数える窓は事前登録に明記がなかったので、実行前に 252 本（Da ほか 2014 の形成期間＝PRET と同じ窓）に固定。(2) データの最終日は事前登録の「2026-07」ではなく 2026-06-30。判定規則は変更なし。

## 判定（事前固定）

R² と FIP のそれぞれで、前後半とも 差>0 かつ 年単位 t≥2 → 支持。どちらかの期間で 差<0 か、両期間とも |t|<2 → 棄却。それ以外 → 未確定。
