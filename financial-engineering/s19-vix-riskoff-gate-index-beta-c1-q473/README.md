## 方法（要点）

- 仮説: pos[t]=1{VIX[t−1] ≤ Q80(VIX[t−251..t−1])}（指数 10 に同じゲート）。高 VIX 局面は株式のボラが高く平均リターンが低い（Moreira・Muir 2017 のボラ管理）ので、リスクオフ局面を外すと規程 C1（σ60 で規模化・保有コスト 4%）の下で t が上がり max_dd が浅くなる。封印前 2012-02〜2024-06・境 2017
- 測るもの: 規程 C1 の t（all/pre/post）・mean_bp・max_dd・worst_day・stops（判定）、ゲートなし（params 1）との差。等金額の年単位 bp・t・z。extra: ゲートが閉じていた日の比率・年別、ゲート閉中の指数リターン平均（記述）
- 帰無: ゲート（0/1）の循環シフト（min_shift=120・B=500）→ 等金額の年単位 bp の帰無分布 → z・perm_p。ゲートの「位置」に情報が無ければ観測は帰無の中央
- 多重比較: 判定は 2 本（Holm で補正）。ほかの設定・群は記述
- 先行研究チェック: WebSearch 2026-10-24「VIX threshold timing equity index exposure risk-off filter backtest out-of-sample evidence volatility managed portfolios Moreira Muir」: Moreira・Muir 2017（前月の実現分散の逆数で規模を変えると株式などでシャープが上がる）、追試の学位論文・WP（ミューチュアルファンドでは効果が弱い）。VIX の rolling 分位の 0/1 ゲートを CFD 保有コスト・固定最大損失・σ0.25% の下で、2012〜2024-06 の前後半で見た追試は見当たらない。itiger 等のニュースは根拠にしない
- 捨てた案の数: 3（族内の試行は params のゲート 3 本〔main・分位 0.9・窓 120〕に固定）。捨てた案: FX22 TSMOM60 と BTC/ETH TSMOM60 に同じゲート（β で効けば別 ID）、キャリー族への VIX ゲート（Brunnermeier ほか 2008 の線。スワップ実装が要るので別 ID）、VIX 水準で連続的に規模を変える（Moreira・Muir の 1/σ² は S04b 系で σ60 と差が無かった）
- 知識の締め切り: Claude の知識の締め切りはおよそ 2026-06。規則は固定で相場観は使わない
- 委託の確かめ方: なし（Fable 設計・実行 → Opus 見直し）。実行者は VIX の asof（t−1）が未来を見ていないことを spec の point_in_time で確かめる

## 判定（事前固定）

等金額: ゲートあり 1.32 bp/日（t 1.08・Sharpe 0.21）対 なし 2.52 bp/日（t 1.97）。帰無（ゲートの循環シフト）に対して **z −2.63**（perm_p 0.994・帰無の 95% 区間 1.49〜2.41）＝ゲートの位置は無作為な位置より**悪い**。分位 0.9（params 2）2.04 bp・窓 120（params 3）1.37 bp もゲートなしに届かない。

なぜ: ゲートが閉じている日（15.9%・2018 年 44%・2022 年 38%・2015 年 30%）の指数の平均リターンは **+8.6 bp/日**（開いている日 +2.7 bp/日）。高 VIX 局面はボラが高いが平均リターンはむしろ高く（下落の後の戻りを含む）、0/1 ゲートで外すと戻りを取り損ねる。Moreira・Muir の効果は「1/σ² で規模を変える」ものであって「高ボラを休む」ではなく、その規模調整は規程モードの σ60 ターゲティングが既に行っている。

点検: `data_health` の gaps は Q468 と同じ（開始前の 2011 年の穴・月内本数比の警告）。VIX の asof（t−1 暦日・閾値は t−1 までの rolling）は 2020-03-10〜13 が閉じていることで確認。`years_dropped` なし。

判定: **棄却**（事前規則: ゲートありの規程 t_all 0.22 ≤ なし 0.46、かつ等金額 z −2.63 < 1）

**解釈: VIX の水準ゲートは株価指数の買い持ちを改善しない。むしろ高 VIX 日を外すことで平均リターンの高い日を捨て、t も最大下落も悪化する。ボラ指数をデータ源に足しても「規模は σ60 で決める」規程モードの上では新しい情報にならない。★ A の 1 源（CBOE ボラ指数）はこれで閉じ、残りは B（前向き標本待ち）のみ。VIX データ自体は `_データ/raw/vol/` に残す（キャリー族のリスクオフ・ゲート〔Brunnermeier ほか 2008〕は別 ID の候補だが、本件の結果から優先しない）。**
