## 仮説
- H1: 総資産の前年比（直近の年次総資産÷1 年前の年次総資産 − 1）が低い下位 10% 買い・高い上位 10% 売りは、コスト後に NW t≥2・前後半とも年単位 t≥2。H0: NW t<1。
## 定義
- シグナル = −(Assets_FY(t) ÷ Assets_FY(t−1 年) − 1)（負号を付けて「上位 10% 買い」の土台に乗せる）。Assets の年次値は fp==FY・end 最大。1 年前の値は end が 300〜430 日前のもの。

## SEC 財務の読み方（Q696〜Q699 共通・`us-sec-value-q696/sec_pit.py`）
- データ: `作業層/大容量/sec/facts.parquet`（EDGAR の XBRL companyfacts・`_データ/fetch/fetch_sec_facts.py`・861 銘柄・filed 2009-04〜）。価格は `equities_free/us_daily.parquet`（調整済み終値）。
- **ポイントインタイム**: 判断日 t（月末）には `filed ≤ t` の行だけ使う。各タグで `end` が最大の値（同じ end なら filed が最新）。
- フロー（純利益・売上・営業 CF）: `fp == "FY"` かつ 期間（end − start）330〜400 日の年次値。ストック（総資産・株主資本・発行株数）: end 最大の値（10-Q を含む）。
- タグの優先順: 純利益 NetIncomeLoss → ProfitLoss。売上 Revenues → RevenueFromContractWithCustomerExcludingAssessedTax → SalesRevenueNet。株主資本 StockholdersEquity → StockholdersEquityIncludingPortionAttributableToNoncontrollingInterest。営業 CF NetCashProvidedByUsedInOperatingActivities。総資産 Assets。株数 CommonStockSharesOutstanding → WeightedAverageNumberOfDilutedSharesOutstanding。
- **分割の補正**: 株数の連続する値の比 r が 1.4 以上（または 1/1.4 以下）で、r か 1/r が {1.5, 2, 3, 4, 5, 6, 7, 8, 10, 20} の ±5% 以内なら分割とみなす。t より後の分割の積を F(t) とし、1 株あたりの値を F(t) で割って調整済み終値の基準に揃える（adjclose(t) = raw(t)/F(t) なので比率は F に依らない）。分割でない跳び（増資・買い戻し）は補正しない。
- **限り**: 価格は配当でも調整されているので、古い日付の「財務÷価格」は配当の累積分だけ大きめに出る（全銘柄に同じ向き・高配当の銘柄がやや割安に見える）。生の株価が手に入れば直せる。README に書く。
- 適格: 共通の適格（株価≥5 ドル・売買代金上位 800・履歴）に加えて、その案に要る財務がそろう銘柄。判断日の最低銘柄数 **200**（SEC の宇宙は 861 銘柄）。
- 期間: 2010-07-01〜2024-06-30（最初の 1 年は filed を貯める）。前後半の境 **2017-07-01**。

## 実装での読み方（2026-11-10 Sonnet がコードを書くときに決めた細部・判定と定義は変えていない・README の「限り」と同じ）
- 分割の補正は、判断日 t の F(t) ではなく「株数を観測した end より後の分割の積」で 1 株あたりの値を揃える（観測日と t の間に分割があると F(t) では株数が分割前・価格が分割後でずれるため。差が出るのは観測日〜t に分割がある月だけ）。
